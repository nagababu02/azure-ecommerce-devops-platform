# Azure E-Commerce DevOps Platform (Terraform + Jenkins + ACR + AKS + ArgoCD)

An end-to-end cloud-native DevOps platform on Microsoft Azure implementing **Infrastructure as Code (IaC)**, **Continuous Integration (CI)**, and **GitOps Continuous Delivery (CD)**.

## Tech Stack
* **Cloud:** Microsoft Azure (`uaenorth`)
* **IaC:** Terraform + Helm Provider + Azure Blob Remote State
* **CI:** Jenkins + GitHub Webhooks
* **Registry & Orchestration:** Azure Container Registry (ACR) + Azure Kubernetes Service (AKS)
* **GitOps CD:** ArgoCD
